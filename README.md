# Poço Vivo — MVP

Plataforma comunitária para registrar, encaminhar e acompanhar problemas de abastecimento até a confirmação da solução.

**Status:** protótipo demonstrativo em desenvolvimento. Ainda não opera infraestrutura real.

## Escopo inicial
- Registro e acompanhamento de ocorrências.
- Triagem por regras locais, com integração opcional com IA.
- Encaminhamento apenas para responsáveis cadastrados e confirmados.
- Histórico de atualizações e providências.
- Simulador de falhas de alimentação, motor e telemetria.
- API documentada, banco local SQLite e testes automatizados.

A documentação e o código completo serão adicionados neste repositório em commits subsequentes.
