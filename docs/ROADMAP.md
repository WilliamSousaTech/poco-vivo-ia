# Roadmap — 12 semanas

| Semanas | Atividade | Evidência |
|---|---|---|
| 1–2 | Entrevistas e mapa do processo real | Fluxo e responsáveis identificados |
| 3–4 | Requisitos e protótipo navegável | Fluxo revisado por perfis de usuário |
| 5–6 | API, SQLite, eventos e estados | Testes de API |
| 7–8 | Triagem local + IA opcional | Comparação com revisão humana |
| 9–10 | Simulador de telemetria e testes | Relatório reproduzível |
| 11 | Sessões de usabilidade autorizadas | Problemas de uso registrados |
| 12 | Revisão, documentação e demonstração | Próximo backlog e limites explícitos |

A duração é estimativa de planejamento, não garantia de implantação em campo.
